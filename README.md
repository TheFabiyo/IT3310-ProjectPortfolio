# IT3310 Project Portfolio

## Fabian Rodriguez
**Course:** IT 3310 - IT Project Management  
**Role:** Associate Consultant, NovaTech Consulting

## Project Overview

This repository contains my project management portfolio for IT 3310. 
Throughout the semester, I will be working from the perspective of an 
Associate Consultant at NovaTech Consulting.

The project focuses on Riverside Community Health Network (RCHN), a 
healthcare organization operating six community clinics. RCHN is 
preparing to replace its aging patient intake and scheduling system. 
Throughout the project, I will develop project management artifacts 
covering initiation, planning, execution, monitoring and controlling, 
and project closure.

## Portfolio

This repository will be updated throughout the semester as each
